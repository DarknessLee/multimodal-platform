## 4. 关键校验点

- **一单制**：主运单 + 3 分段运单 + 5 单证 + ISSUE 事件 + 哈希链存证；存证 verify 通过。
- **单证**：POD 上传 → Mock OCR（箱号/签收人/日期/数量）→ Mock CA 签章（signHash 64 位）→ 存证。
- **箱管**：放箱/提箱/进场/装箱/还箱状态联动、堆存 80 元/天、箱损维修。
- **调度**：三方案策略齐全，COST 成本最低、TIME 时长最短、评分 0~100；确认后事务签发运单。
- **财务**：明细和=账单总额、应收-应付=毛利、税额按 9%；对账/发票/支付/保理状态机闭环；超额支付 42201。
- **集成/监管/运营**：适配器健康与测试、批量重试、监管报送状态机、5 类合规检查、配置/字典/任务/健康、全链路检查。
- **权限**：12 角色菜单/操作隔离，越权 40301。

## 6. Mock 边界与已知简化

- 全部外部系统 Mock：95306、港口 EDI、CA、银行、税务、保险、监管、GPS；无真实网络/证书/资金流。
- 区块链为本地哈希链；发票无 OFD/PDF 签章；地图为 ECharts 经纬度视图（无瓦片）；IoT 无 MQTT Broker。
- 调度评分/合规检查为确定性规则（非 AI）；定时任务为手动触发 Mock 调度。
- 数据中台以 `stat_daily` 汇总表模拟 ADS，未做完整 ODS/DWD/DWS 分层。
