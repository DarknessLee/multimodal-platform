# 接口契约（多式联运供应链协同平台 V1.0 · 索引）

> 统一前缀 `/api`；JSON camelCase；JWT（`Authorization: Bearer <token>`）。
> 响应：`{ code: 0, message: "ok", data: ... }`；分页：`{ list, total, page, pageSize }`。
> 本文件是最终接口索引；字段级细节以 `api/src/modules/**` 与服务响应为准。

---

## 1. 通用约定

### 错误码

| code | 含义 |
|---|---|
| 0 | 成功 |
| 40001 | 参数校验失败 |
| 40101 | 未登录/Token 失效 |
| 40301 | 无权限 |
| 40401 | 资源不存在 |
| 40901 | 当前状态不允许操作（如重复出账、未签收出账） |
| 40902 | 重复操作（重复开票/重复确认/重复重试成功报文） |
| 42201 | 业务规则校验失败（如超额支付、CRITICAL 有未处置工单禁止关闭） |
| 50000 | 服务端异常 |

### 核心状态机

- 订单：`CREATED → CONTRACTED/CONFIRMED → DISPATCHED → IN_TRANSIT → ARRIVED → SIGNED → BILLED`（可 `CANCELLED`）
- 分段：`PENDING → ACCEPTED → IN_TRANSIT → ARRIVED → COMPLETED`
- 运单：分段状态联动，签收后 `SIGNED`
- 预警：`OPEN → ACK → CLOSED`（CRITICAL 关联未处置工单禁止关闭）
- 账单：`ISSUED → PAID`（部分核销保持 ISSUED）
- 对账：`DRAFT → SENT → CONFIRMED / DISPUTED`
- 发票：`PENDING → ISSUED → VOID`
- 支付：`PENDING → SUCCESS / FAILED`
- 保理：`SUBMITTED → APPROVED / REJECTED → SETTLED`
- 监管报送：`DRAFT → SUBMITTED → ACCEPTED / RETURNED`
