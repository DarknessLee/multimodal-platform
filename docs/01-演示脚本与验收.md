## 5. 演示注意事项

- **角色菜单差异**：权限由 `role_permission` 种子控制，`admin01` 可见全部；承运人/港站为只读监控；监管仅监管菜单。
- **签收后出账**：订单需为「已签收」，结算中心才出现待出账卡片。
- **重复操作**：重复出账 40901、重复开票 40902、重复确认预警 40902、批量重试 >20 条 40001，均为预期业务校验。
- **数据恢复**：演示前可执行 `npm run db:init` 回到干净种子。
- **构建 esbuild Temp 权限错误**：将 `TEMP`/`TMP` 指向项目内 `.tmp`。
- **修改前端源码后 dev 异常**：重启 `npm run dev`。
