## 5. 排错

| 现象 | 处理 |
|---|---|
| API 启动报数据库连接失败 | 确认 MySQL 已启动；检查 `api/.env`（`mto_demo / Mto_demo_2026`） |
| 登录 40102 | 账号/密码错误；演示密码 `demo123` |
| 角色菜单缺失 | 角色权限由 `role_permission` 种子决定；确认 `npm run setup` 已执行 |
| 报价无价格规则（40903） | 检查线路/箱型/模式是否有生效价格规则 |
| 「当前状态不允许该操作」 | 按状态机顺序操作（报价 DRAFT→SENT→ACCEPTED；订单调度前可取消等） |
| 集成报文 FAILED | 集成中心「重试」；成功后不可重复重试（40902） |
| 构建报 esbuild Temp 权限错误 | 将 `TEMP`/`TMP` 指向项目内 `.tmp` 后重试 |
| vite watcher EBUSY | 修改 web 代码后重启 `npm run dev`（已忽略原子写临时目录） |
| 想恢复初始数据 | `npm run db:init`（重建 26 表与 v1 种子） |

## 6. 演示话术（1 分钟版）

> 这是一套平台化的多式联运演示：货主可以在线询价，平台按线路、箱型、客户协议价自动分段计价并生成报价；
> MTO 发送报价、与货主在线签署框架合同；货主接受报价即生成订单。之后 MTO 人工调度，
> 公路承运人接单提货、港站完成进场与到港到站，系统持续追加 mock 轨迹；货主查看全程轨迹并签收，
> 结算一键出账，账单金额自动等于各分段费用之和。平台运营可以在总览看板、集成中心（95306/港口 EDI/CA/银行/税务 Mock）
> 和审计日志中看到全过程数据。所有数据均为 Mock，但编码（ISO 6346 箱号、统一社会信用代码、UN/LOCODE/车站电报码）、
> 价格与时效、单据号、报文结构均按真实业务标准生成。
